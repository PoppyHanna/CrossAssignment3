# Coffee Shop UI — Cross Assignment 3

A React Native project created as part of **Cross-Platform Programming — Cross Assignment 3**.

The project demonstrates the implementation of reusable React Native UI components based on a Figma design. The interface supports different screen orientations and includes reusable components, responsive layouts, interactive states, and platform-specific styling.

## Project Preview

The application represents a reusable component set for a coffee shop mobile interface.

The UI is based on the Figma design created in the previous assignment and includes product cards, form elements, buttons, and bottom navigation.

The components are designed to be reusable and receive dynamic data through props.

## Implemented Components

The project contains **7 reusable React Native components**:

- `SearchInput` — search field with an icon
- `SizeButton` — selectable coffee size button
- `PromoCodeInput` — promo code input with an action icon
- `VerticalProductCard` — vertical coffee product card
- `HorizontalProductCard` — horizontal coffee product card
- `CustomButton` — reusable action button
- `BottomTabBar` — bottom navigation with icons and active states

Each component is stored in a separate file and receives dynamic data through props.

## Features

- Reusable React Native components
- Component data passed through props
- Responsive portrait and landscape layouts
- Flexbox-based positioning
- Adaptive layout using `useWindowDimensions()`
- Platform-specific styling using `Platform.select()`
- Centralized color constants
- Material Design icons
- Interactive size selection
- Active bottom navigation states
- Search and promo code inputs
- Vertical and horizontal product card layouts
- Safe area support

## Responsive Design

The application supports both **portrait** and **landscape** orientations.

`useWindowDimensions()` is used to adapt selected component dimensions depending on the available screen width.

The layout was tested in both orientations to ensure that components remain readable and properly positioned.

## Platform Adaptation

Platform-specific shadows are implemented using `Platform.select()`.

Different shadow properties are applied for:

- **iOS** — `shadowColor`, `shadowOffset`, `shadowOpacity`, and `shadowRadius`
- **Android** — `elevation`

This allows the components to maintain appropriate native styling on different platforms.


## Design

The interface was implemented based on a Figma UI design.

The project uses centralized color constants to maintain consistent styling across components.

Main design elements include:

- warm coffee-inspired color palette
- rounded cards and controls
- product images
- active and inactive component states
- Material Design icons
- responsive product layouts
