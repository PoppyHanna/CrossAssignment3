# Coffee Shop UI — Cross Assignment 3

React Native проєкт, створений у межах домашнього завдання **Cross-Platform Programming — Cross Assignment 3**.

Проєкт демонструє реалізацію багаторазових UI-компонентів React Native на основі дизайну у Figma. Інтерфейс підтримує різні орієнтації екрана та містить адаптивні компоненти, інтерактивні стани й платформозалежні стилі.

## Огляд проєкту

Застосунок представляє набір багаторазових компонентів для мобільного інтерфейсу кав'ярні.

UI створений на основі Figma-дизайну з попереднього завдання та містить картки товарів, поля введення, кнопки й нижню навігацію.

Компоненти є багаторазовими та отримують динамічні дані через props.

## Реалізовані компоненти

Проєкт містить **7 багаторазових React Native компонентів**:

- `SearchInput` — поле пошуку з іконкою
- `SizeButton` — кнопка вибору розміру напою
- `PromoCodeInput` — поле введення промокоду з іконкою дії
- `VerticalProductCard` — вертикальна картка товару
- `HorizontalProductCard` — горизонтальна картка товару
- `CustomButton` — багаторазова кнопка дії
- `BottomTabBar` — нижня навігаційна панель з іконками та активними станами

Кожен компонент зберігається в окремому файлі та отримує динамічні дані через props.

## Адаптивний дизайн

Застосунок підтримує **portrait** та **landscape** орієнтації.

`useWindowDimensions()` використовується для адаптації розмірів окремих компонентів залежно від доступної ширини екрана.

Інтерфейс протестований в обох орієнтаціях, щоб компоненти залишалися читабельними та правильно розташованими на екрані.

## Адаптація для платформ

Для платформозалежних тіней використовується `Platform.select()`.

Для різних платформ застосовуються відповідні властивості:

- **iOS** — `shadowColor`, `shadowOffset`, `shadowOpacity` та `shadowRadius`
- **Android** — `elevation`

Це дозволяє компонентам використовувати відповідне стилізування залежно від платформи.

## Стилізація

Стилі компонентів створені за допомогою:

`StyleSheet.create()`

Для побудови макета використовуються Flexbox-властивості:

- `flexDirection`
- `justifyContent`
- `alignItems`
- `flex`

Кольори винесені в окремий файл констант, щоб уникнути повторення однакових значень у різних компонентах.

## Дизайн

Інтерфейс реалізований на основі UI-дизайну у Figma.

Основні елементи дизайну:

- тепла палітра кольорів у кавовій тематиці
- заокруглені картки та елементи керування
- фотографії товарів
- активні та неактивні стани компонентів
- Material Design іконки
- адаптивне розташування карток
